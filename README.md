Project Title: Spendwise Application

Project Description: My project allow users to keep track of daily spending by recording expenses names, amounts, categories and days to better encourage money management and savings.
Technologies used: I used HTML, CSS, and JavaScript to do the coding and deployed project on netlify.com

GitHub Repository Information: The repository name is web-week-7-assignment while the url is https://github.com/lilbabe-dev/web-week-7-assignment.git

Live Netlify Website URL: https://anokbudget.netlify.app/

Deployment Process Summary: I started by creating Netlify account and connected in to github account. I imported the project from the github repository and deployed. I checked it severally to make sure the preview is good enough. I made sure the project is set to public so that it can be accessible to everyone with the link.  

Challenges Encountered During Deployment: I encountered several challenges. I did not know how to use the netlify platform to deploy the project. Navigating the platform was a great challenge to me. Furthermore, I did not know to import the project from the github to netlify account. However, through several attempts, I managed to import and finally deployed the project. After deployment, it was hard to set the project to public for people to view but I managed to overcome this challenge at the end and set my project to public. 

Lessons Learned: I should have done some basic research about the deployment process before anything.
